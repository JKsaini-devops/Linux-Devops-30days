# Linux-Devops-30days
My 30-day hands-on Linux administration and shell scripting learning journey

Day 1 Topic: Linux File System Hierarchy (FHS) & Navigation
Key Learnings: /var/log management, /etc configurations, Absolute vs. Relative paths (..).

Day 2 Topic: File management & File viewing Tool
Key Learning: cat, more, less, head and tail.( for view) cp, mv, ( for copy and move), rm , rm -r ( for remove) tail -f ( for live streams) 

Day 3 Topic: Text Processing and Filtering
Key Learning: | (Pipe), grep, cut, sort and uniq, 

Day 4 Topic: User and Group Administrator
Key Learning: useradd, usermod -aG, /etc/passwd, /etc/shadow, and visudo

Day 5 Topic: File permissions & Access Control List
Key learning: Permission Ownership type( User, Group, Other) Permission Type (Read,write,Execute), chmod, chown, chgrp, numeric permissions, and setfacl/getfacl.

Day 6 Topic: Package Management & Repositories 
Key Learning: apt, dpkg, yum, sources.list, and dependency management, Difference between 'apt update and apt upgrade', High level and low lever packing tool.

Day 7 Topic: Reviews and Lab Practical assessment
Key Learning: yum update, yum install tree, groupadd, useradd, cut, sort, uniq etc..

Day 8  Topic: Process management and service control
Key Learning: What is PID, Process status (R,S,Z,), Monitoring Tool (ps,top,htop), kill, systemctl 

Day 9 Topic: Disk & Storage Management 
Key Learning: df -h, du -sh, lsblk

Day 10 Topic: Network and Remote Connectivity 
key Learning: Network Interface, ip address, Service Port, Ping, ssh
